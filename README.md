# 残域

以灯阁为基地、以残域为副本的单机放置 Roguelite 手游（纯静态网页，手机竖屏）。

**在线试玩**：https://miano-design.github.io/wxlh-game/

**装到手机上玩**（推荐，装一次以后断网也能玩）

- **iPhone**：用 Safari 打开上面的网址 → 底部「分享」→ **添加到主屏幕** → 桌面出现「残域」图标，
  点开就是全屏、没有地址栏
- **安卓**：用 Chrome 打开 → 右上角菜单 → **安装应用 / 添加到主屏幕**
- 判定版本：打开游戏的「设置」，最底下的版本号要与仓库最新版本一致（例如 `V9.5`）；
  资源都带版本号，正常情况下打开就是最新的

## 玩法

- 🌀 **残域**：**20 个残域 × 3 难度 × 12 关**（共 720 关），点进去就打、1~3 波一口气连打（打完自动接下一波）、血量波间继承、Boss 机制战
- 👥 **角色收集**：**120 名执灯者**，六维属性 / 升星 / 技能 / 六大血统 / 铭刻五阶
- ⚔️ **回合战斗**：速度出手、暴击闪避、10 种异常状态、阵营克制、Boss 70%/30% 阶段
- 🎒 **装备养成**：6 种品质、随机词条、6 部位（主角与招募角色都是 6 槽）、世界套装 2/4/6 件、职业套装、+20 强化
- 🔒 **装备管理**：锁定保护（锁定后不参与分解、不被一键换装）、一键最优装备、与当前穿戴红绿对比、批量分解
- 🧰 **道具背包**：消耗品 / 经验模块 / 强化材料 / 装备箱分类，宝箱与经验模块支持 1 / 10 / 全部批量使用，点任意道具看「说明 / 在哪用 / 去哪弄」
- 🎒 **背包页签**：背包是一级页签（不再藏在弹窗里），卡片上直接给「开 / 喂 / 服 N」快捷键
- 🏠 **首页五段**：**主角 → 主线 → 养成 → 游历 → 挂机 → 设置**，一个功能只有一个入口（不重复、不用找）；
  「养成」里用一行小字「日常」分出悬赏 / 每日任务 / 成就 / 求签 / 招募 / 兑换，「游历」只放游历奇遇；
  挂机卡上的「一键收取」把所有已达成未领取的奖励一次收完
- 🎯 **三张招募池**：**花三种货币、出三种结构** —— 普通池（◈点数）攒碎片、高级池（✦圣洁晶石）补图鉴且优先给未拥有、限定池（◆异界结晶）定向出当期 UP（50 抽必出），保底按池分开记账
- 🎫 **招募券**：三个池各配一张券（引灯招募券 / 圣契招募令 / 异界征召令），副本、悬赏、每日/周常、登录、商店都能掉；**有券先用券，券不够才扣货币**，十连不混扣。招募页底部有「📊 概率公示」，逐池写明每一档出率、保底抽数与还差几抽
- 🔑 **灯阁权限**：10 级高级货币长线投资（✦圣洁晶石 + ◆异界结晶），永久提升挂机产出 / 挂机经验 / 离线上限 / 离线效率 / 每日扫荡次数，满级额外全队全属性 +5%，**转生不清空**
- 🧩 **阵型**：6 种具名阵型（双子阵 / 三才阵 / 四象阵 / 五行归元阵 / 双柱阵 / 四海阵），队伍页直接显示成阵情况与加成；**主角是万能补位**，可顶任意阵营名额
- 🖐 **长按拖拽换位**：站位区**长按抓起**任意一人（含主角）、**按住拖到目标位置松手就放下**；拖动中手指底下的格子实心高亮、空位显示「放这里」，拖回原地或点顶部提示条上的「取消」都是放回原位（抓起后点一下目标位置也能放）；抓起不弹提示框，只给一下轻震动
- ↺ **洗点**：主角的**六维**和**技能**都能随时洗（免费、可反复），加错了不用重开档
- 🛡 **主角可站后排**：前排吃伤害、后排躲伤害，主角站哪一排由你定（战斗里真的按选择的排站位）
- 🔒 **装备唯一**：一件装备只能被一个人穿——换给别人时自动从上一个人身上摘下，老存档里的重复穿戴开档自动修好
- ⚡ **编队与自动**：3 组编队预设一键切换、自动战斗开关（直接出结果）
- ⏳ **放置挂机**：在线/离线收益、基地五大建筑加成、防改时间
- 🧭 **挂机分工**：4 条产线（闭关修炼 / 灵材采集 / 外围探索 / 灯阁守卫）各派 1 名领队，产出看领队的**对应六维**（闭关=精神 / 采集=肌肉 / 探索=神经 / 守卫=免疫，封顶 +150%），上阵主力不能派 —— 板凳角色的用处
- 🐾 **伴生体 + 五行克制**：第二条养成线。孵化兽魂石得伴生体，给全队加属性；金木水火土相克，带对属性进本全队伤害 +15%、带反 -8%（在战斗伤害公式里结算）
- 🔥 **限时悬赏**：4 条带截止时间的目标，**按你的当前进度动态生成**（推进当前世界 / 等级 / 强化次数 / 深井 / 图鉴 / 伴生体 / 渡劫），到点作废，结束后可开新一期
- 🌌 **境界渡劫**：**9 大境 × 初/中/后/大圆满 = 36 小阶**（炼气初期 → 渡劫大圆满），约每 2.6 级就能破一阶，单阶全属性永久 +1.4%（36 阶合计 +50.4%）；渡劫失败只扣材料、**等级不掉**，可反复挑战。老存档按「旧第 N 境 = 新第 4N 阶」自动迁移
- 🔁 **推图连续性**：战斗结算页直接给「↻ 再来一次 / › 下一关」，最后一关自动顺延到下一难度、下一世界
- ⏱ **结算自动接关**：胜利结算 **8 秒**内没做选择就自动接着打下一关（设置里可关；失败页不自动跳，没有下一关时也不跳）
- 🌱 **药园**：4 块灵田，花 ◈点数种下、到点收强化材料（离线也计时），**收货价值约等于投入的 1.2 倍**（比用点数补材料划算），面板上逐块写明"花多少 → 收什么"，支持「一键全收」
- 🥋 **斗法台**：每天 5 次镜像擂台，守擂者按你队伍战力换算，赢一场升一台拿 ◆异界结晶 + ♜深井徽记，输了退一台不会卡死
- 🔮 **法宝**：主角同时带 1 件，给的是**效果**（吸血 / 开场能量 / 减伤 / 闪避），花 ◆异界结晶买，随时能换
- 🐎 **坐骑**：给的是**基础数值**，而且**全队通用（含招募角色）**；花 ◈点数 + 强化材料驯服，高阶另加 ◆异界结晶，只骑 1 匹随时换
- 🎋 **求签**：每天免费摇一次，五档签文（大吉→末吉）给**当天挂机加成**（+6%~+30%）与一笔硬通货，摇之前就公示各档概率
- 🏯 **灯阁评级 / 📜 秘术阁 / 🧭 游历奇遇**：打关卡自动涨的全局评级（每级全队 +0.5%）、42 条百分比长线、挂机每 10 分钟一次随机奇遇
- ♾ **深井**：无限爬塔终局玩法 + 深井商店；「深井印记」每 10 层 +1.5% 深井内属性（上限 +45%），越爬越强
- ♻ **转生系统**：四支永久天赋树（40 个节点全部实装，文案与效果同源），轮回重生
- 📜 **任务系统**：主线 16 步引导 + 每日 8 条 + 周常 5 条（周一重置，全清奖励）+ 20 项成就（战斗/养成/收集/挑战）
- 🔊 **手感与保护**：手机返回键接管（先关面板再退页面）、副本进度实时落盘（刷新/切后台可续打）、合成音效
- 🎛 **五条全局交互规则**：热区 ≥44px、同按钮 300ms 防连点、货币收支 ±数值跳动、成功/失败回执（失败抖动）、大额消费二次确认（可在设置里关）
- ❓ **玩法指南与货币图鉴**：在首页最后一段「设置」里，逐章讲清副本、站位、装备、货币、血统、深井；顶栏的货币点一下就看用途与来源
- 📱 **手机优先**：断点覆盖 375 / 340 窄屏，正文上边距跟着顶栏实际高度走，键盘弹出时弹窗自动上移，长文案一律有断行兜底
- 📕 **角色图鉴**：收集进度 + 里程碑奖励
- 🧹 **便捷功能**：可选关卡与次数的扫荡（每日 60 次）、自动分解白装 / 绿装
- 📮 **待领箱**：背包满时收到的奖励（任务 / 药园 / 挂机材料 / 悬赏…）不会丢，先存进待领箱，背包页一键领回
- 🧪 **药剂只治活人**：探索里的治疗剂不能复活已阵亡的成员，星级评价里"无人阵亡"是真的

## 存档

存档保存在浏览器 localStorage（saveVersion 5，旧档自动迁移到 6 装备槽并补齐新字段），支持 3 个手动存档槽 + JSON 导出/导入。
