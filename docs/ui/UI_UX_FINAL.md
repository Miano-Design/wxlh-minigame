> 版本：NARRATIVE-UX-FINAL-2026-10 · 状态：**正式**

## 一、页面分三级，语义不许混

| 级 | 例子 | 顶栏 | 底栏 | 返回 |
|---|---|---|---|---|
| **一级** | 灯阁 / 残域 / 执灯者 / 背包 | **不摆标题条** | 有 | 无（根页） |
| **二级** | 世界详情 / 卷宗记录 / 伙伴详情 / 装备详情 | 吸顶返回 | 无 | 回上一层 |
| **三级及浮层** | 战斗 / 剧情 / 结算 / 确认框 | 剧情页免打扰；战斗页只有关卡名 | 无 | 关闭当前层，不改页面层级 |

规则：

- 一级页**不要**"‹ 标题"那条顶栏 —— 点了也没地方去，白占一条；
- 返回**永远**回上一层；「关闭」只关浮层；「取消」是放弃操作；「完成」留在当前功能；
- 同一页**最多一个视觉第一焦点**。

## 二、四个一级页各回答一个问题

| 页 | 回答 | 首屏必须有 |
|---|---|---|
| **灯阁（首页）** | 我是谁 · 我在残域的哪儿 · 下一步做什么 | 主角卡 → 当前旅程（W## + 世界名 + **一句世界现状** + 进度 + 继续探索） |
| **残域** | 我打到哪了 | 当前世界那张卡（进入当前世界）→ 深井（**单独一节**）→ 世界线（**按六卷分组**） |
| **执灯者** | 我带的是谁 | 队伍 / 伙伴 / 各条养成线的入口 |
| **背包** | 我有什么 | 道具 / 材料 / 装备 |

首页的信息优先级（从上到下）：

```
① 我是谁       主角卡（境界 / 等级 / 主角 / 转生 四行）
② 现在做什么   当前旅程 +【继续探索】   ← 屏幕上唯一的主按钮
③ 现在有什么   挂机收益 +【领取】（有才出现）
④ 刚刚发现     只在没读过时出现；读完就消失，历史进卷宗
⑤ 今天 / 常去   宫格（只放最常用的，不铺按钮墙）
⑥ 导航         底栏四格
```

> **首页不是功能菜单。** 商城 / 抽卡 / 装备 / 法宝 / 命格 / 坐骑 / 药园 这些不许抢第一视觉层。

## 四、卷宗页：先看"查到什么"，再看"看过什么"

第一屏是【调查记录】：

```
调查记录            当前 W18 等一个不会回来的人
┌────┬────┬────┬────┐
│ 12 │  3 │  2 │  1 │
│已确认│待确认│矛盾│核心线索│
└────┴────┴────┴────┘
卷宗 18 / 107 · 打完一个世界，就会捡到它留下的记录
```

下面五个页签：**记录 / 残域 / Boss / 人物 / 装备**
（页签上**不放数字** —— 五个半字宽的格子塞数字，320 屏会糊成一片；数字在上一张卡里）。

点一条记录进二级页：

```
卷宗编号 → 记录类型 → 状态 → 正文 → 相关世界 → 关联卷宗 → 灯阁备注
```

**关联卷宗是可以点进去的** —— 两份记录摆在一起，玩家自己看出哪对不上。

### 捡到关键记录的那一刻（发现感）

```
战后剧情读完
  ↓ 画面短暂压暗
W29-004                     互相矛盾
磨剩的两个字
第九座残影台底下有一道磨过的刻痕。不是名字，只剩两个字：来过。
        【保存至卷宗】
```

**不许**用普通 Toast 说"获得卷宗"：那四个字没有信息。

## 五、战斗：机制要看得见，结果要说人话

| 阶段 | 要求 |
|---|---|
| 开打前 | Boss 出场序列（2.4 秒、只放一次）＋ 这个世界那句机制说明 |
| 战斗中 | 事件驱动残响（首次命中 / Boss 血量阈值 / 机制触发）——**每场至少 3 个节点** |
| 打完了（世界里的战斗） | 大标题【**记录完成**】＋ 战场变化＋ **卷宗 新增记录 ×N** ＋ 下一步 |
| 打输了（世界里的战斗） | 大标题【**调查中止**】＋ **为什么停**（一句，由真实战斗数据算出来）＋ 按钮 |

> ⚠️ 只有"调查场次"这么叫。深井 / 斗法台 / 扫荡**不是调查**，仍然说「胜 利 / 战 败」。
> 把打擂台也叫"调查"是错的。

## 六、按钮

### 三态

```
正常    →  处理中  →  完成 / 禁用
【保存至卷宗】→（点下去）→（卡片消失，记录进册）
```

### 主次

| 类 | 例子 | 反馈 |
|---|---|---|
| **主按钮** | 继续探索 / 进入世界 / 确认执灯 | 按下缩放 + 亮度 + 音效 + 状态变化 |
| **次按钮** | 详情 / 查看 / 切换 / 筛选 | 轻反馈 |
| **导航** | 底栏 / 返回 | 更轻 |
| **卡片** | 世界卡 / 记录卡 | 整张可点，不许"只有一角像按钮" |

### 文案

按钮**必须看得懂**。可以把关键入口写成世界观的叫法（【点灯】【翻阅卷宗】），
但**不许把所有按钮都改成玄学文案** —— 看不懂的"氛围命名"是 bug。

## 七、反馈优先级（Toast 不是万能反馈）

```
① 界面状态直接变      装备 → 装备槽立刻出现装备
② 数字直接展示        攻击 120 → 136
③ 一次性奖励才用 Toast 获得 ◉ 1200 / 获得「…」×1
④ 界面已经明显变了     就不许再补一句 Toast
```

失败必须回答**为什么**和**下一步怎么办**：

```
✗ 操作失败
✓ 点数不足 · 需要 ◉ 1200（还差 380）
✓ 装备格已满 · 请先扩容
✓ 今日扫荡次数已用尽 · 明天再来
```

---

## 八、不许再"加东西"

这一轮的目标是**信息层级更清楚、交互更明确、界面更有质感**，不是元素更多。

发现某页太挤 → **删 / 合并 / 分组**；发现太空 → 调布局。
不许用"再加一层装饰 / 再加一个标签 / 再加一颗按钮"掩盖层级问题。
