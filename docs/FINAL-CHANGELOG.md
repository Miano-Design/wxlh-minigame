## 三、重新实现 / 重写的地方（不是"选一个版本"）

1. **`game.js` 补了一条真实的 P0**：`js/sc-story-battle.js`（R1.6 的 Boss 出场序列 / 事件驱动残响 /
   战后世界变化）**从来没有被 game.js 加载过** —— 它只进了尺子环境（旧 `_env.js` 按 `^sc-.*` 全局加载），
   于是**尺子全绿、真机一次都没跑**。这正是任务书 §15 禁止的"审计环境才生效"。
   → 已按真实顺序补上 require，并**根治了它赖以发生的机制**（见 3）。
2. **`scripts/_env.js` 的加载清单改成从 `game.js` 派生**（正则读 `require('./js/xxx.js')`）。
   以前是"7 个基础文件 + 所有 `sc-*.js`"，任何不叫 `sc-` 的层都不会被加载 ——
   现在**真机加载什么，尺子就加载什么**，以后加文件也不用回来同步。
3. **`js/overhaul-2.0.js` 去掉"重复接管返回"那一段**：它原来包 `BattleUI.run` 记快照 + 覆盖
   `battle_close` 落地时换 `CV.stack`。BASE 从 R1.2 起就有 `B.back` 做同一件事
   （`battle_return_audit` 16/16），两套同时管返回＝§15 明令禁止，而且 `battle_close` 是
   **四条战斗入口（副本/深井/斗法台/挂机）共用**的一个全局动作名，覆盖它会一起改写四条的语义。
   → 保留它的 battle HUD 机制条（有价值），去掉返回接管。
4. **宫格锚点前缀统一**：`overhaul-2.0.js` 原来用 `ov_today / ov_quick / ov_growth_more` 作
   `U.tiles` 的整块锚点 id —— 项目里这一类统一叫 `grid:`（`grid:grow`/`grid:daily`），
   `audit_pages`/`ux_audit` 的白名单也按 `grid:` 判。→ 改成 `grid:ov_*`（同类同前缀）。
5. **Boss 血量系数按实测再调 12 格**：2.1 已把 Boss 从"海绵"拉回来，但实测仍有 12 个世界
   TTK 21~39 回合（§五 区间是 3~20）。→ 只降"超标那几格"（W17/19/21/23/25/26/27/29/31/32/34/35），
   **没超标的 12 格一格没动**（动了只会把 Boss 变成秒杀）。复测：超标世界 **12 → 4**。

## 五、最终工程只有一条运行路径

- 入口只有一个：`game.js`（`GAME_VER = '2.1.0'`）。
- 三层各司其职、不互相覆盖：`js/sc-story*.js`（故事）→ `js/overhaul-2.0.js`（旅程 UI）→ 其余 `js/sc-*.js`（页面）。
- 不存在"审计环境才生效"：`_env.js` 的加载清单**从 game.js 派生**。
- 不存在两套状态机：剧情状态只有一个读取入口 `Story.stateOf(wid)`（R1.8 收口）。
- 不存在两套结算返回：`battle_close` 只有 BASE 那一套（上面 §三-3 已删掉 2.0 的第二套）。
