## 四、世界 → 世界钩子链

> `transition`（上一站的出口）必须被下一站的 `premise` 接住 —— `story_continuity_audit` 逐对核。

- **W01** 墙不是长，是在重放同一段 → 沿着黏液来的方向走　⇒　下一站：顺着黏液走，尽头是一个档案站的走廊
- **W02** 有人曾从里面撬门出去 → 往档案编号指向的下一个区　⇒　下一站：顺着编号，走进一栋还亮过的旧宅
- **W03** 怨声是没说完的话，不是别的什么 → 屋契背面记着下一个地址　⇒　下一站：按地址找过来，是一座封着石门的地下墓室
- **W04** 石卫守的不是宝物，是一条没人解除的规则 → 门后面不是墓，是一条通到外面的路　⇒　下一站：那条路通到一片被雾封住的林子
- **W05** 它一直在保护一个已经没有了的东西 → 雾散的方向有水声　⇒　下一站：水声尽头，是一座沉在地下的城
- **W06** 灯能不让一件事结束 → 水退干净的地方，露出一个往下的口　⇒　下一站：顺着往下的口，是一座被挖空的矿坑
- **W07** 石头里的光不是矿，是活的 → 矿脉断口朝上，顺着它往上走　⇒　下一站：顺着矿脉断口上去，是一个被黑潮淹过的港口
- **W08** 这里曾经是出口，但没人走成 → 航道尽头是一片被灰盖住的地　⇒　下一站：航道尽头是一片被灰盖住的地
