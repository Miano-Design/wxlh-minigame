> 数据真源：`js/sc-story-overhaul-data.js` 的 `ARCHIVE`；运行时接口：`js/sc-story.js` 的 `Story.*`。

## 一、卷宗不是"看过的剧情存起来"

卷宗是：

> **玩家调查残域留下的证据库。**

区别在哪：

| 旧口径（已经不作数） | 现在的口径 |
|---|---|
| 剧情读完 → 把文字存进去 | 打完一个世界 → **捡到这个世界的记录** |
| 一页一页的剧情目录 | 一条一条**有编号、有状态、能互相对照**的证据 |
| 只能读 | 能顺着**关联卷宗**点过去，两份一对照就看出哪对不上 |

## 二、六种记录类型

| 类型 | 它记的是什么 | 例子 |
|---|---|---|
| **世界卷** | 世界本身的历史 | W06-001「淹到街口的那一年」 |
| **人物卷** | 角色 / Boss / 异常存有 | W18-002「归航信标」 |
| **事件卷** | 玩家亲历的那件事 | W29-005「它不拦人」 |
| **灯阁卷** | 灯阁内部记录（最危险的一类） | W36-002「执灯者记录 第 001 次」 |
| **异常卷** | 与现有记录**冲突**的信息 | W36-005「第 000 次：记录状态 不存在」 |
| **残缺卷** | 无法确认真假 / 缺了一页 | W04-002「碑文背面」 |

## 三、五种状态

```
核心记录   core        金色 —— 主线钉在这条上
互相矛盾   conflict    危险色 —— 这里有问题，而且我们不知道哪边是对的
待确认     pending     异常色 —— 有人报过，但还没验
残缺       fragment    灰 —— 缺一页，或者只剩两个字
已确认     confirmed   增益色 —— 这条为真
```

> **状态不是进度条。** 玩家读到的是内容，不是"我收集了 37%"。
> 卷宗页上那四个数字（已确认 / 待确认 / 矛盾 / 核心）是**线索的分布**，不是成就。

---

## 四、编号规则

```
W##-NNN     例：W18-031
 │   └── 这个世界里的第几条（按建立顺序，不按玩家发现顺序）
 └────── 它属于哪个世界
```

编号**一旦发布就不许改**：它在剧情台词、结算页、关联跳转里都会被引用。

## 五、关联（这套系统的价值全在这里）

每条记录的 `refs` 指向别的记录。**关联在数据层自动补成双向**
（`sc-story-overhaul-data.js` 装载时会把 A→B 补出一条 B→A），
否则玩家从 B 点进去看不到 A，"两份记录对不上"这件事就发现不了。

### 主线关联链（必须一直存在）

```
W03 ─→ W08 ─→ W13 ─→ W18 ─→ W24 ─→ W29 ─→ W34 ─→ W36
屋契   撤离   不是    出现在   第一次   第九座   四十二   第 000 次
重名   未完成 第一次  两栏     自己动手 残影台   个版本   不存在
```

### 五组"互相矛盾"（§二十）

| 组 | 矛盾在哪 | 记录 |
|---|---|---|
| W03 / W08 | 同一件事，两个人名，两份都盖了章 | W03-002 ↔ W08-001 |
| W07 / W13 | 同一天的停工理由，一份写材料，一份写"它醒了" | W07-003 ↔ W13-003 |
| W18 / W24 | 同一个名字同时出现在出发栏和返航栏 | W18-005 ↔ W24-004 |
| W25 / W29 | "第 39 次修正"和"这是第一次修正" | W25-001 ↔ W29-004 |
| W30 / W34 | 三条路里的空方向，和汇点里编号 043 的空格 | W30-004 ↔ W34-004 |

> **不许告诉玩家哪份是真的。** 这一套的全部意义就是让他自己拼。

## 六、什么时候"捡到"

```
打完一个世界的守关 Boss
   ↓
结算页：【记录完成】＋ 卷宗 新增记录 ×N W##-NNN、W##-NNN …
   ↓
继续 → 战后剧情逐句读完
   ↓
黑底记录卡：「W##-NNN · 一句关键内容 · 【保存至卷宗】」
   ↓
卷宗页查到它；顺着关联卷宗往下点
```

三条口径：

1. **记录是打完才捡到的**，不是打开卷宗页就自动全给你；
2. **发现卡一次一张、只在这个世界第一次通关时给**（重读不会再弹）；
3. **重刷不会重复报"新增记录"**（收卷是幂等的）。

## 七、数量口径

```
一般世界        ≥ 2 条
关键世界        ≥ 3 条   （W03 / W07 / W08 / W13 / W25 / W29 / W34）
六个核心 Boss   ≥ 5 条   （W06 / W12 / W18 / W24 / W30 / W36）
W29 / W36       ≥ 5 条
```

**但不许为了凑数灌水。** 一条记录至少要满足一项：有信息 / 有出处 / 有状态 / 有关系。
盯这条的是 `scripts/archive_relationship_audit.js`。

## 八、写作纪律

允许：

```
屋契落款一个字：灰。上一任屋主的名字被人从纸面上刮掉了。
```

禁止：

```
这是一份非常神秘而又重要的档案，它似乎隐藏着什么不为人知的秘密……
```

**记录是证物，不是散文。** 一句话能说完就一句话；说不完就分成两条，不要写成一段。
