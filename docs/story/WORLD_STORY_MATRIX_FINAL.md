## 一、每行八格怎么读

```
表层问题   玩家一进来看到的那件事（ARC.premise）
隐藏问题   这个世界真正不对的地方（ARC.anomaly）
玩家目标   玩家自己给自己定的目标（ARC.playerGoal）
机制       真正进战斗的那条规则（ARC.battleMechanic == Battle.MECHANICS[wid]）
Boss       守关的是谁（BOSS[wid].name）
卷宗       这个世界留下了几条记录（ARCHIVE[wid].length）
战后       打完以后世界变了什么（ARC.environmentChange）
伏笔       下一步往哪走 / 留下了什么（ARC.clue → ARC.transition）
```

## 三、36 个世界的"独立"是靠什么保证的

`narrative_content_audit.js` 硬量三件事，任何一条退步都会当场红：

1. **36 条核心异常互不重复** —— 换个名字套同一句话的做法会立刻暴露；
2. **36 条机制互不相同、而且都被 `battle.js` 真读** —— 写在数据里没人读的"机制"不算；
3. **每个世界 ≥3 个事件驱动的战斗反馈** —— 玩家打这一场要真的看得见机制。
