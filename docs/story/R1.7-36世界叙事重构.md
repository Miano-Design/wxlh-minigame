## 四、闪屏 P0（根因与修法）

**根因**（`sc-story.js` `Story.bg` / `CV.veils.battle`）：函数只有两条路 ——
「有图就画图、没图就画程序化」。而"没图"其实分两种，它混成了一种：
- **还在加载**（正常路径）→ 先画程序化 → `img.onload` 补一帧 → **玩家看到"旧画 →（闪）→ 新画"**；
- **加载失败**（真 fallback）→ 画程序化是对的。

**修法**（`Story.sceneState()` 三态）：
```
ready   → 正式场景图
loading → 主题平底（CV.THEME_TINT，无几何、无暖灯）——看起来是"画还没显影"，不是另一张画
failed  → 才走程序化保险（bgBase + bgStructure）
```
配套**预热**：开机（`game.js`）、进世界页、开打前各调一次 `Story.preloadWorld()`，
让 loading 这段尽量发生在玩家还没看到这一页的时候。战斗页的 veil 用**同一份判断**，不另写一套。
