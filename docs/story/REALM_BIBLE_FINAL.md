## 一、残域是什么

残域**不是异世界**。

它是：

> **已经结束、正在崩坏、被删除过，或者被某种力量强行保存下来的世界残片。**

这些世界本来应该消失。但是在毁灭、重构或记录异常发生之前，被**灯阁**记录并保存了下来。

所以玩家进入的不是"另一个世界"，而是：

> **一个被保存下来的世界版本。**

**这决定了 36 个世界的样子**：它们不是"六个国家、三十六座城"，而是**同一个文明留下的三十六份存档**。
每一份都在某个时刻被按下了暂停：有一层还在往外长的墙（W01）、有一条已经跑了很多年的轨道（W06）、
有一座一直在过同一天的城市（W16）、有一座还没启动的重启点（W33）。

> ⚠️ **它们不是"末世废墟"，是"仓库里的样品"** —— W22 那句"残域是人类主动造的，不是灾难的残余"
> 就是把这件事说白的那一次。在那之前，玩家应该只感觉到"这些地方停得不太自然"。

## 二、灯是什么

灯不是武器，也不是法器。它有四种功能：

| 功能 | 意思 | 玩家第一次见到它的地方 |
|---|---|---|
| **记录** | 把一个世界记下来 | W01 战后：灯扫过去，那面墙退了一寸 |
| **固定** | 把某一时刻固定住 | W06：沉城停在"水淹到街口"那一年 |
| **连接** | 把不同的世界接起来 | W15：之前见过的东西在核心外面环聚了一遍 |
| **重载** | 把某个存在过的状态重新载入 | W12：这条街的第十七遍 |

但是：

> **灯并不能保证"记录"就是事实。**

这是第六卷才让玩家看见的那件事，也是整个游戏最后那个问题的一半。

---

## 三、核心谜题（唯一的一个）

整个游戏始终围绕一句话：

> **一个被保存、复制、重载的世界，还是原来的世界吗？**

它慢慢扩大：

```
世界可以被保存
  → 记忆可以被保存（W21）
  → 人的状态可以被保存（W17）
  → 人的行为可以被重载（W12 / W16）
  → 玩家自己的经历也可能被记录（W15 / W29）
  → 那么"现在的玩家"究竟是不是第一次来到这里？（W34 / W36）
```

**纪律：前六个世界不许把这个问题讲出来。** 玩家应该自己感觉到不对：

- 第一，墙在重放同一段（W01）——但没人解释为什么；
- 第六，Boss 说"你比记录里晚了六分钟"（W06）——但没人解释"记录"是什么；
- 第十二，Boss 说"你每次都会在这里忘掉一件事"（W12）——**还是不解释**。

解释这件事**只在 W29 / W34 / W36 发生**，而且只说一半。

---

## 四、玩家身份

玩家是**执灯者**。但**不要开局解释**。

玩家应该先经历：

```
进入残域 → 发现自己会使用灯 → 发现灯能打开被封存的世界
→ 遇到第一个认识自己的人 → 开始怀疑
→ 之后才逐渐发现："执灯者"不是出生身份，是一份被反复保存的职责。
```

**这条顺序不许提前。** 谁在第一卷就写出"你是执灯者，你负责……"，谁就把后面五卷的冲击全花掉了。

## 六、九碑（卷五的落点 · W29）

W29《回头看一遍》的最后灯塔周围浮着**九座残影台**：

```
前八座：上面有名字。第八座刻的是玩家的名字。
第九座：空着。
第九座底下：一道已经磨过的刻痕。不是名字，只剩两个字——
```

> **来过**

灯阁那边的记录写着：

```
【灯阁旧录 W29-009】
九个位置从建立之日起就已经存在。
八个位置有过名字。
第九个位置从未有人登记。
备注：不要让第九个位置拥有名字。
```

**这一处必须与前面的线索接上**：W02 的"从里面撬开的门"、W13 的"你不是第一次走到这里"、
W18 的"出现在两栏里的同一个名字"、W24 的"第一次自己动手关掉一个世界"——
它们都是同一件事在四个不同世界留下的痕迹。

> ⚠️ **W29 不是审判，是回头。** 它不拦人，它要人把这一路看一遍。
> 谁把 W29 写成"最终 BOSS 大战"谁就跑题了。

## 七、W36：两个结局

W36 不是"打 Boss → 选按钮 → 结束"。它是：

```
战斗 → 灯阁记录被打开 → 玩家看到自己的第一次记录
→ 发现"第一次"可能并不是第一次 → 玩家必须做决定
```

战后台面上滚出来的那份记录（`ENDING.ledger`）：

```
执灯者记录 第 001 次   状态：已完成   结论：不可回收。   处理：重新载入。
执灯者记录 第 002 次   状态：已完成   结论：仍拒绝熄灯。 处理：重新载入。
……
执灯者记录 第 042 次   处理：重新载入。
执灯者记录 第 000 次   记录状态：不存在。
```

然后才是选择：

### 【让灯熄灭】

灯灭。世界一个一个熄。玩家发现自己手里的影子也在变淡。

> 「这一次，没有人重新点亮它。」

### 【继续点燃】

灯重新亮起。整个灯阁重新亮起。最远处，第九座残影台第一次出现了名字。

> 不是别人的名字。是你的名字。
> 【第 043 次记录开始】

**两个结局都成立。** 不写"哪个是对的"：

```
A = 世界终止
B = 世界延续
```

主题留给玩家自己判断。结尾**不许解释玩家是不是死了**。

## 八、三条硬纪律

1. **不要让故事和画面打架。** 剧情说"这里没有人"，画面上就不能满屏 NPC；
   剧情说"Boss 认识你"，Boss 的第一句就不许是"你是谁"。
2. **不要把解释塞进台词。** 玩家要的是"我又想起一件事"，不是"下面由我来解释设定"。
3. **不许提前泄底。** 世界几就只说世界几该说的话；提前一句，后面五卷就白写了。
