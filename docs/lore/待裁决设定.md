## 2. `DESIGN_REVIEW` 三位世界 Boss 是不是七碑创始人本人

- **现状**：`js/data.js` 里 W11 Boss＝`幽帆船长`、W18 Boss＝`白衣院长`、W21 Boss＝`终场演员`。
- **冲突**：本稿要凑齐"九碑前七位执灯者"，而现成的名字只有四个阵营之祖（灰 / 雾 / 锈 / 幽）有落点，
  另外三位（帆 / 白 / 默）**没有对应的活人**。
- **本稿暂用口径**：把这三位 Boss 设定成**创始人本人**——

  **没有新增任何角色、没有改名**，只是给了现有 Boss 一个身份。
- **需要拍板**：同意 / 不同意。
  不同意的话，七碑里的帆 / 白 / 默就只是三个已经不在场的名字，
  W11 / W18 / W21 三场 Boss 战的叙事分量会掉一档（他们只变成"这个世界最后留下的东西"）。

## 4. `DESIGN_REVIEW` 白河秋的跨阵营

- **现状**：`js/data.js` 的 `CHAR_TABLE`：`C115 白河秋 · 灰原 · 绯红 · 终极刺客 · UR`。
  他同时是**绯红血统的 power 第一**，绑了专属武器 `绯河刃`。
- **冲突**：本稿给他的本命故事是"出身幽都，因救命之恩把名字留在灰原"——
  **故事起点在幽都，阵营在灰原**。而灰原与幽都是全书理念对立最硬的一家对一家。
- **本稿暂用口径**：**保留灰原阵营**（数据不动），故事用"救命要还、还不上就把名字留下"解释。
  这条正好呼应绯红的接口规则（生命交换），是有意设计的。
- **需要拍板**：这个解释要不要保留。不要的话，两种改法：
  ① 把本命故事改成纯灰原出身（弱化，但省事）；② 把阵营改幽都（**要动数据与阵营克制，不建议**）。

  界面/数据里"命格"更多挂在**养成层**：命格实验室、命格神装、血髓晶、"命格升级"。

- **需要拍板**：接受这个解释 / 还是要把界面统一改成"血统"（**要动 45 处文案**，建议留到专门的文案轮）。

## 12. `DESIGN_REVIEW` 深井与渡口是两条"出口"说法

- **现状**：推广文案写的是"**传闻在残域最深处的'深井'之下，藏着离开这里的唯一办法**"；
  玩法指南把深井写成"层数无限递增的终局玩法"；本稿 W35 又把"九幽渡口"写成离开残域的传说入口。
- **冲突**：一个说出口在深井底下，一个说出口在渡口。**两套说法。**
- **本稿暂用口径（建议照此定）**：
  > **深井往下 = 往灯阁最早的记录走；井底就是渡口。**
  > 所以"深井底下有离开的办法"这句话是真的 —— 只是渡船的对岸通向的是**灯阁**，不是外面。
  > 这正好解释 W35 那句"没有一个真正到岸"。
- **需要拍板**：确认这条合并（**它会让深井从"没有剧情的刷层玩法"变成有剧情的地方**）。
