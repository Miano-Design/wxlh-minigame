# 《残域》世界观总纲

> A 批产出（纯策划稿，不接代码）。真源：`js/data.js`（36 世界 / 四阵营 / 六血统 / 装备与套装）、
> `js/dungeon.js`（`THEME_FACTION`）。本文件只写"世界怎么运转"，不写具体剧情。

---

## 一、一句话

**残域不是一个废土，是大量已经毁灭、正在毁灭、被舍弃、被封存的世界残片，
被一座叫「灯阁」的建筑用「灯」一盏盏保存着。**

玩家推进的不是"地图"，是**别人世界的最后一页**。

---

## 二、七个基本词

| 词 | 定义 | 关键约束 |
|---|---|---|
| **残域** | 由大量「世界残片」拼成的域。不是自然形成的废墟，是**被保存/被舍弃的结果** | 后期才揭穿，前期一律当"危险的破碎地带"处理 |
| **世界残片** | 一个曾经存在过的世界，留下来的那一部分。可能完整、可能只剩一段走廊 | 一残片 = 一个游戏世界（W01~W36），不得再拆 |
| **灯** | 能对一个世界做五件事的器物：**记录 · 固定 · 连接 · 封存 · 重载** | **一灯对一世界**。灯的核心定义全程不变 |
| **灯阁** | 观测残域、保存世界、筛选世界、管理执灯者的地方 | 它本身就是一盏不会熄的灯。它不"拯救"，它"保存" |
| **执灯者** | 能进入残域、并与灯建立连接的人 | 与灯连接的深度 = 境界（渡劫 = 加深连接） |
| **血统** | 你适合以哪一种方式与灯连接。是**身份**，不是职业 | 六支固定：狼人 / 泰坦 / 修真 / 念动力 / 绯红 / 科技 |
| **灯芯与铭刻** | 灯芯＝灯阁这盏灯烧的那根芯；铭刻＝把"自己"刻进灯里 | 两者共同构成"你够不够清晰，可以被重新加载" |

---

## 三、灯能做的五件事（全程不准改）

1. **记录**：把一个世界的此刻写下来。（灯录 = 灯阁的记录册，游戏里就是图鉴两卷。）
2. **固定**：让被记下的那一刻不再变化。（禁忌实验区 = 连春天都停住了的固定。）
3. **连接**：让两个本来互不相干的世界残片接在一起。（世界之间的通道、阵营来往都从这来。）
4. **封存**：把已经结束的东西锁起来，不删也不放。（沉眠城主执行的就是这一条。）
5. **重载**：按记录，把封存过的东西重新加载出来一次。（**转生**。）

**这五件事都是善意的。** 这才是残域的悲剧——没有人做过一件坏事，世界却停不下来了。

---

## 四、核心矛盾（全书只有一个母题）

> **被保存、复制、重载的世界，还是原本的世界吗？**

三条支线全部从这个母题长出来：

- **保存派（灯主 / 创造者意识）**：只要灯还亮着，文明就没有真正消失。→ 于是没有任何世界被允许结束。
- **送行派（幽都）**：已经结束的，就该让它结束。反复重载只是不肯承认。→ 于是残域永远少一次"真正的告别"。
- **中间态（灰原 / 雾乡 / 锈港 / 大部分执灯者）**：往前活着，不去想这件事。→ 于是残域照常运转，谁都不需要回答。

**玩家是唯一被逼着回答的人。**

## 五、五种残片质地（＝ `data.js` 里的 `theme`）

世界残片按"它保存下来的是哪一层"分五种质地。**这不是美术分类，是归属分类**：
质地决定这片残片归谁管、原住民是谁、敌人是哪儿来的。

| theme | 质地名 | 保存下来的是 | 辖区 | 世界数 | 世界 |
|---|---|---|---|---|---|
| `bio` | **滋生** | 身体与活物本身 | **灰原** | 8 | W01 W02 W09 W10 W16 W23 W28 W33 |
| `ghost` | **残响** | 意识、记忆、没散去的人 | **幽都** | 9 | W03 W05 W07 W08 W15 W18 W21 W27 W31 |
| `mystic` | **秘仪** | 规则、仪式、被写下来的秩序 | **雾乡** | 7 | W04 W11 W12 W13 W24 W29 W35 |
| `tech` | **造物** | 造物、机器、被执行的命令 | **锈港** | 7 | W06 W17 W19 W22 W26 W30 W34 |
| `god` | **神域** | 灯阁自己写下的场 | **灯阁直管（无阵营）** | 5 | W14 W20 W25 W32 W36 |

> 计数与 `js/data.js` 的注释一致（bio 8 / ghost 9 / mystic 7 / tech 7 / god 5 = 36）。
> `docs/story/叙事素材系统-第一期.md` 原来写的是 bio 9 / ghost 10 / tech 7 / mystic 6 / god 4，
> **已于 2026-10-01 修正**（提交 `e9684e3`，`scripts/audit_story.js` ⑫ 现在会守住这一条）。

**神域为什么无阵营**：这五个世界不是"别人的世界"，是灯阁自己搭的场
（试炼 / 回廊 / 法庭 / 创造者核心 / 王座）。它们是主场，所以敌人名单里才会出现「另一个你」。

## 六、六支血统的世界观解释（身份，不是职业）

灯连接一个人，需要一条"接口"。血统就是接口的形状——
**它决定你能从灯里读到什么、灯能从你身上写下什么。**

| 血统 | 接口方式 | 世界观解释 | 绑定阵营倾向 |
|---|---|---|---|
| **狼人** | 身体适应 | 把世界的变化直接长在身体上。饿、痛、恢复，都由身体自己算 | 灰原（前线） |
| **泰坦** | 身体重构 | 身体可以被重造。承下来的伤会变成结构，不是损失 | 灰原 / 锈港 |
| **修真** | 能量感知 | 能"读"出残片里还没散尽的规则与流向 | 雾乡 |
| **念动力** | 意识连接 | 能直接连上别人的意识，也能被别人的意识连上 | 幽都 / 雾乡 |
| **绯红** | 生命交换 | 一切连接都要付代价，用命换命，用记忆换力量 | 幽都 |
| **科技** | 机械 / 数据连接 | 把连接做成可复制、可修复、可传下去的东西 | 锈港 |

**排他性**：一支血统只有一条接口，所以**血统即定位**（游戏内 `bloodline` 直接决定战斗模板）。
血统套装 / 血统神装只有同血统的人穿得上——这在世界观里不是规则限制，
而是**别的血统读了会烧掉**：接口对不上。

## 七、两条时间尺度（写作时必须分清）

### ① 残片内部的时间
残片停在被保存的那一刻。里面的世界可能同时在"运转"：
感染还在蔓延（W01）、雪还在下（W13）、宴会还在开（W15）。
**它们不是活着，是没被按停。**

### ② 灯阁的时间
灯阁不按时间走，按**加载次数**走。

> 同一个世界可以被读很多次，每次读出来都略有不同（蚀环就是反复读取留下的褪色）。
> 于是"第几次醒来"在灯阁里是一个实数，而在玩家的记忆里是零。

**这解释了游戏机制，不需要另加设定**：

- 世界进度 / 深井层数 **保留** = 世界这一侧是"被保存的数据"，重载不影响它。
- 玩家等级 **重置** = 被重载的是"你"这一份拷贝，不是世界。
- 玩家 **不记得** = 灯阁只重载身体，不重载记忆（它认为记忆是负担）。

## 八、游戏内已有名词 → 世界观含义（一律沿用现名，不改）

| 现名 | 世界观含义 |
|---|---|
| **灯阁评级**（60 级） | 灯阁对执灯者"能承多大一份连接"的评定 |
| **灯芯**（建筑） | 灯阁这盏灯的芯。它越亮，能带的拷贝越清晰 |
| **铭刻**（`geneLock`，铭魂砂） | 把"自己"刻进灯里。刻得越深，重载得越完整 |
| **转生** | 灯阁按铭刻重载一次"你"。要求 = 铭刻 2 阶 + 灯芯 Lv.20 起（逐次抬高到 5 阶 / Lv.40） |
| **深井** | 灯阁往下的账本竖井。越深越接近最早的记录；传说"离开这里的办法"在底下。**井底就是 W35 的渡口**——所以那句传说是真的，只是对岸通向的是灯阁，不是外面 |
| **点灯** | 每天替灯阁校准一次灯焰（五档：长明 / 炽光 / 明光 / 柔光 / 微光） |
| **灯录**（图鉴两卷） | 灯阁自己的记录册。伙伴卷 = 它记下的人，装备卷 = 它收下的东西 |
| **异界结晶 ◆** | 灯阁结算给执灯者的"世界碎片" |
| **圣洁晶石 ✦** | 更纯的碎片，只在最高一档的连接里产出 |
| **转生点 ♾** | 只有重载时才会掉出来的东西——**它本来就是"你上一次剩下的"** |
| **灯阁残片**（T5 强化材料） | 灯阁自己的旧灯罩碎下来的料 |
| **铭魂砂 / 血髓晶** | 刻字用的砂 / 接口要用的髓 |
| **命格神装（神话）** | 灯阁为六支接口各写死的一套"标准形状" |
| **本命（专属）** | 灯阁记下的某个人的形状，做到了装备上 |

## 九、三条底线（任何一卷都不许破）

1. **灯的定义只加不减**：记录 → 固定 → 连接 → 封存 → 重载。可以后揭开，不可以前后打架。
2. **残域不是自然废墟**：它是"被保存"的结果。谁都不许把它写成"末日后的荒地"。
3. **灯主不是反派**：他做的一切都出于善意（不让文明消失）。他的错误只有一条——
   **他不愿意接受"世界已经应该结束"。**
