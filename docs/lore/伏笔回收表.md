## F-01 名字

| 项 | 内容 |
|---|---|
| 首次出现 | **W01** 名牌背面刻着一个字——**灰** |
| 首次表现 | 玩家以为那是死者的名字（或者这个世界的名字） |
| 玩家表面理解 | 这些世界名里的字，是地名里的字 |
| 真实含义 | **它们是人名**。九碑前七位执灯者的名字，被后人拆成了地名 |
| 中途强化 | W04「雾」· W11「帆」· W15「幽」· W18「白」· W21「默」· W22「锈」· W28（世界自己在记玩家的字迹） |
| 正式回收世界 | **W29 最后灯塔** |
| 回收文本 | 守誓者不看碑，只看自己的手：**"前七个是凿的。第八个，是刻的。"**（玩家自己把七块碑上的单字与地名对上） |

## F-02 记忆

| 项 | 内容 |
|---|---|
| 首次出现 | **W07** 裂晶巨兽："你上次梦到一半就走了。" |
| 首次表现 | 玩家当它是幻觉（这一卷的标准反应） |
| 玩家表面理解 | 残域里的东西在胡说 |
| 真实含义 | **灯阁重载时不给记忆**，所以"上次"在玩家这里是零 |
| 中途强化 | W12（"你不是第一次走到这里"）· W18（病历不是第一本）· W25（判决书核对） |
| 正式回收世界 | **W31 最初残域**（墙还回来的是更早的自己） |
| 回收文本 | 墙还回来的那句话，**是玩家自己在 W13 说过的一句**，声音更旧、更累 |

## F-03 重载

| 项 | 内容 |
|---|---|
| 首次出现 | **W01** 黏液母巢每次重生都重复同一段动作 |
| 首次表现 | 玩家只觉得这是个烦人的机制 |
