# 《残域》核心人物

> 原则：**每个核心人物至少要推动一个事件或一个谜团。** 推不动的人不写进来。
> 血统 / 阵营 / 稀有度一律取自 `js/data.js` 的 `CHAR_TABLE`（现名不改）。
> "第一次出现"是**叙事上的首次露面**，不等于抽卡池开放时间。

## 〇、主角（执灯者）

| 项 | 内容 |
|---|---|
| 角色 | **执灯者**（玩家本人，名字由玩家起） |
| 阵营 | 无（开局四家都不认你；W04 之后四家都认得你） |
| 血统 | **玩家自选六选一**（开局第一件事，`BLOODLINE_UNLOCK_LV = 0`） |
| 第一次出现 | 开屏「提灯入残域」 |
| 表面身份 | 一个被卷进残域的人 |
| 真实身份 | **第八位执灯者**（碑八）。第一批执灯者的同代人 |
| 与主角关系 | —— |
| 核心欲望 | 前期：活下去 / 推下去。中期：知道自己是谁。后期：让这件事结束 |
| 核心冲突 | 他每一次变强，都是被重载一次。**玩家越强，"我到底是什么"越说不清** |
| 结局状态 | W36 做出选择（熄灭 / 继续点燃）。**第一期不给对错** |
| 相关世界 | 全 36；身份线集中在 W03 W07 W12 W18 W20 W24 W25 W29 W32 W36 |
| 相关伏笔 | F-01 名字 / F-02 记忆 / F-03 重载 / F-05 第八个名字 |

**关于"玩家起的名字"（重要机制耦合）**：

游戏里有自由命名，玩家输入的名字**就是碑八上那行字**。这是全书最强的一击，也是最大的工程风险：

- 剧情引用玩家名字时，**必须复用同一套内容安全校验**（`js/sc-namecheck.js` 已存在）；
- 玩家**没起名 / 起名失败**时，剧情里一律显示「**未署名**」（不许显示空、null、报错码）；
- W18 / W24 / W25 / W29 四处引用名字的地方，**文案里不写死任何一个名字**，只用"和你署名一样的那行字"这种指代；
- 名字被改动过（后续改名）时，旧记录里保留**旧名字**——这本身就是伏笔（"上一次的字迹和这一次不一样"）。
