# 《残域》核心谜团

> 六大谜团的**分层揭示表**。写作纪律：**每一层只准说到这一层**，超前的信息一律压后。
> 判定"能不能说"的方法：看 `玩家当前认知` 那一行，只写它以后的那一格。

---

## 谜团一：残域是什么

| 阶段 | 世界 | 玩家的理解 | 真相进度 |
|---|---|---|---|
| 前期 | W01~W06 | 一片很乱的废墟，世界一块一块拼在一起 | 0% |
| 中期 | W07~W18 | 这些"废墟"太整齐了——走廊、名单、病历都还在原位 | 30% |
| 后期 | W19~W24 | 不是废墟，是**被保存下来的世界**。星骸遗址里堆着无数文明的最后一刻 | 70% |
| 终局 | W25~W36 | 残域 = 由大量世界残片组成；**它之所以还在，是因为有人不肯让它结束** | 100% |

**不许提前说的词**：W18 之前一律不出现"保存""封存""残片"这三个词。

## 谜团二：灯是什么

| 阶段 | 世界 | 玩家的理解 | 真相进度 |
|---|---|---|---|
| 前期 | W01~W06 | 照亮残域的东西。灯阁靠它活着 | 记录（读者不知道） |
| 中期 | W07~W18 | 灯不只是照亮——灯亮着的地方，那一段残片"不会变" | 固定 |
| 后期 | W19~W30 | 灯在**保存世界**。每一盏灯对应一个曾经存在过的世界 | 保存 |
| 终局 | W31~W36 | 灯还能**重载**世界。而**灯也是残域停不下来的原因之一** | 重载 |

**五件事的揭示节奏**：记录（W12）→ 固定（W13）→ 连接（W20）→ 封存（W24）→ 重载（W32）。

**写作禁令**：
- W18 之前，任何角色都**不准**直接说"你来过""你上次"这类整句；只准用"你"、
  "又"、"还是那个字迹"这种**当事人自己也没想通**的说法。
- W29 之前，**石碑上第八个名字不得被读出来**。玩家可以看见"第八个位置是空的"，
  但内容留白（一个刚被刻开、还没落字的凹槽）。

## 谜团四：转生是什么

| 阶段 | 玩家的理解 |
|---|---|
| 第一次转生前（W12 末） | 一种变强的代价：把等级清掉，换永久天赋 |
| 第一次转生后（W13 起） | 醒来时有事不对——**世界没变，只有你变小了** |
| W19~W24 | 转生不是"复活"，是**被读出来一次**。世界是原件，你是副本 |
| W25~W30 | 你已经被读过不止一次。第八块碑说明：**第八次之前也有过** |
| 终局 W36 | **灯主就是那个一直按下"重载"的人。** 他每一次都希望你这一次能走到最后 |

**与游戏机制的对齐（这条是硬约束，不许改设定去迁就文案）**：

```
转生   → 灯阁按铭刻 重载一次「你」
  保留  → 残域世界进度、深井层数（世界那一侧是保存数据）
  重置  → 等级（被重载的是你的身体）
  不给  → 记忆（灯阁认为记忆是负担，它只留"记录"）
```

> 因此：**"转生 = 重置" 与最终真相不但不冲突，转生本身就是那条真相的演示。**
> 之前那一版 bug（转生把世界进度和深井进度一起重置）在设定上是**错的**——
> 世界是原件，只有你是副本。这条已单独记进 `待裁决设定.md` 备案。

**转生门的四道门也在设定里**（`REINCARN_REQS`）：铭刻 2 / 3 / 4 / 5 阶，灯芯 Lv.20 / 30 / 35 / 40。
世界观解释：**你要被读得越来越清楚，灯芯也要越来越亮，才带得动下一卷那么沉的残片。**

> 这九块碑不是纪念碑，是**座位表**。
> 灯主一开始就刻了九个位子，留给"将会来的九个人"。
> 所以第八个名字你还没来，它已经在了——因为写它的人，一直在等你回来。

## 谜团六：终焉·灯主

### 他不是反派（这条是硬约束）

| 项 | 内容 |
|---|---|
| **立场** | 只要灯还亮着，文明就没有真正消失。保存不是囚禁，是"还没到告别的时候" |
| **他的错误** | **他不愿意接受"世界已经应该结束"** |
| **他做过的好事** | 造了第一盏灯；建了灯阁；把无数将要消失的世界留下来了；每一次都把你重新点亮 |
| **他受的代价** | 他自己从那以后没有熄过。他不是活着，是没被按停 |
| **与主角的关系** | 他写下第八个名字；他按下过每一次重载；他一直在等这一次 |
| **他最终的问句** | **"你愿不愿意让灯熄灭？"** |

### 三次立场交锋（W24 / W30 / W36）

- **W24（转述）**：灰袍祭司——"灯主也只是想留住你们。"
- **W30（正面）**：熔芯核心——"你关掉的每一炉，都有人在天亮前冻死。灯主数过。你数过吗？"
- **W36（本人）**：灯主——"你愿不愿意让灯熄灭？"

**他不劝、不威胁、不反悔。** 问完就等。这才是他最难打的地方——他不是要赢，他是要你承认你说得出那句话。
