# 《残域》剧情总纲

> 这一份是"怎么讲"，不是"讲什么"。
> 讲什么 → `W01-W36剧情策划表.md` / `mysteries.md` / `chapters.md`。
> 怎么讲 → 本文件。

---

## 一、最终体验目标（一句话）

> **边玩游戏，边看一部持续展开的小说。**

而这句要落地，靠的是**五条线同时往前走**：

| 玩家在做的事 | 拿到的叙事 |
|---|---|
| 推进世界 | **剧情**（小说正文） |
| 获得角色 | **人物故事**（三则：首次获得 / 成长 / 特殊事件） |
| 获得装备 | **世界线索**（世界套装 = 那个世界最后发生了什么） |
| 击败 Boss | **解锁下一章**（卷末 cliffhanger） |
| 转生 | **逐渐接近世界真相**（每一次转生都是一次"被读到"） |

**不是**：`副本 → 奖励 → 数值 → 下一副本`。

---

## 二、三条叙事纵轴（不许只走一条）

### 纵轴 A：世界线（自下而上）

玩家在 W01 学到的每一条规则，都在 W36 有对应。

```
W01 母巢反复重生        → W32 万灯之座演示重载
W03 山吹替人关灯        → W36 你自己选要不要熄
W06 世界被编号          → W19 仓库里只有编号
W08 灯照到的地方雾不进   → W34 说明书："灯有五件事"
W18 病历不是第一本      → W29 第九碑庭
```

### 纵轴 B：身份线（自上而下）

玩家是谁，分六层揭（`mysteries.md` 谜团三）。

```
W01~W06  只是一个进入残域的人
W07~W12  有人认识你
W13~W18  你来过
W19~W24  你跟灯阁有过去
W25~W30  你的名字在旧记录里
W31~W36  你是最早的执灯者之一
```

### 纵轴 C：立场线（不动声色地推）

玩家对"保存"这件事的态度，从**感恩**走到**该不该**。

```
W01~W06  灯阁救了我（感激）
W07~W18  灯阁记得我（好奇）
W19~W24  灯阁在保存所有东西（起疑）
W25~W30  保存是要还的（沉重）
W31~W36  要不要停（选择）
```

**关键**：这条线**不许用台词讲**。玩家只能从**打完之后的感觉**里自己长出来。

## 三、四种文本的写法（每种只干一件事）

| 文本 | 长度 | 只负责 | 绝对不做 |
|---|---|---|---|
| **世界剧情**（进图 / 战前 / 残响 / 战后） | 20~180 秒 | 讲这一片残片**发生过什么** | 不解释设定、不总结、不给结论 |
| **人物故事**（三则） | 每则 1 分钟 | **用事件表现人物** | 不写百科式简介 |
| **装备背景**（一句 / 一段） | 一句或一段 | 给一个**画面**或一句**遗言** | 不写工艺、不写数值 |
| **Boss 战前后** | 短 | 给一句**立场**、一句**心疼** | 不喊口号、不喊"来战" |

---

## 四、语言风格（写死）

**要**：克制 · 冷静 · 有画面 · 有一点诗性。

**不要**：堆辞藻 · 中二喊口号 · 传统网文式大段旁白。

反例（禁止）：

> "这是一个充满危险和神秘的世界。"

正例（要求）：

> "第三盏灯已经灭了。"

然后**让玩家自己问**：为什么是第三盏？

**具体手法（三条）**：

1. **让场景说话**：先给一个可看见的事实，不给解释。（"雪停了，但雪没有化。"）
2. **用别人的嘴说一半**：NPC 只说他能说的那一半。（"上一次你没走到这儿。"）
3. **名字比句子重**：一个单字（灰 / 雾 / 帆）比一段解释有用。

## 五、"不说什么"清单（比"说什么"更重要）

| 阶段 | 不许出现的东西 |
|---|---|
| W18 之前 | "保存""封存""残片""重载"这四个词；"你来过""你上次"这种整句 |
| W29 之前 | 石碑第八个名字的**内容**；任何把七个单字解释成人名的句子 |
| W36 之前 | 灯主的**本人露面**（只许转述与引用，W24 / W30 两次） |
| 全书 | 灯主被写成反派；四大阵营被写成反派；任何"你其实很特别"式的夸奖 |

## 六、五条线的接口（B 批才接，这一轮只留口子）

```
Core.storyOf(worldId)      → 该世界该进度的段落（进图 / 战前 / 残响 / 战后）
Core.charStoryOf(charId)   → 故事 01 / 02 / 03（绑定：首次获得 / 成长 / 特殊事件）
Core.itemLoreOf(itemId)    → 一句背景（世界套装 = 一段）
Core.foreshadow(id)        → 伏笔表（首现 / 强化 / 回收）—— 只给内部校验用，不直接给玩家看
Core.mysteryTier()         → 当前该说到第几层（由世界进度算）—— 防"说早了"的兜底
```

> ⚠️ 本轮**只写策划稿，一行代码都不接。**
> 上面这五行是给 B 批留的接口草图，**不是本轮的产出**。

## 八、主角的开局背景（B 批接入时用，正片里只给一句）

**正片里只给的一句**：

> 你在一场无人知晓的异象中被选中，坠入残域。这里没有出口，没有归途，
> 只有一座孤零零的灯阁，为你亮着最后一点光。

**策划层的完整设定**（不在正片里说，供后续使用）：

- 第八位执灯者不是"被随机选中"的。他是**被写下名字的人**。
- 他自己不记得这件事，是因为**这个名字不是他自己写的**。
- 他在 W29 之前的所有怀疑，都不是"想起"——是**"认出来"**。

> ⚠️ 这一条与"开局选血统"不冲突：**选血统 = 选择接口的形状**，
> 灯主写的是"你会来"，不是"你会是哪一支"。**血统必须由玩家自己选。**
