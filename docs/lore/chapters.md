# 《残域》六卷结构

> 卷的边界**不是随便切的**：它和游戏里的**转生门**是同一件事。
> `js/data.js`：W13 要转生 1 次、W19 要 2 次、W25 要 3 次、W31 要 4 次。
> 也就是说——**每翻一卷，你都得被重载一次。**

```
第一卷 W01~W06   门：无
第二卷 W07~W12   门：无（卷末强制第一次转生 → 进第三卷）
第三卷 W13~W18   门：转生 1
第四卷 W19~W24   门：转生 2
第五卷 W25~W30   门：转生 3
第六卷 W31~W36   门：转生 4
```

> ⚠️ 严格说，"转生门"落在**新一卷的第一张图**（W13 / W19 / W25 / W31）。
> 叙事上的处理：**卷末（W06/W12/W18/W24/W30）留下 cliffhanger，转生就是过场，
> 新卷第一图（W13/W19/W25/W31）是"醒来之后的第一个世界"。** 这是全书最重要的节奏装置。

---

## 第一卷《灯下之地》

| 项 | 内容 |
|---|---|
| 世界 | W01~W06 |
| 卷题 | 灯下之地 |
| 主题 | **第一次进入残域** |
| 玩家认知 | 我只是掉进了一个很危险的地方；灯阁是庇护所，灯是照明的 |
| 卷内的成长 | 从"被灯照着的人"变成"提着灯的人"（执灯者） |
| 阵营戏份 | 四阵营各露一面：灰原（W01/W02）、幽都（W03/W05）、雾乡（W04）、锈港（W06） |
| 卷末 Boss | **W06 沉眠城主**（沉眠水城） |
| 卷末 cliffhanger | 主控在停机前吐出一句编号——**这个世界是编了号的** |
| 埋下的伏笔 | 碑一「灰」（W01）、灯不只是照明（W02 灯下没有影子）、碑二「雾」（W04）、世界之间有连接（W05） |
| 必须成立的事 | 玩家在这一卷**真的什么都不懂**。任何"你其实很特别"的暗示都不许给 |

**这一卷的功能**：让玩家喜欢上灯阁。后面每一卷都要靠这份好感才有杀伤力。

---

## 第二卷《雾中的人》

| 项 | 内容 |
|---|---|
| 世界 | W07~W12 |
| 卷题 | 雾中的人 |
| 主题 | **有人认识玩家** |
| 玩家认知 | 残域里有东西认得我。可我不认识它们 |
| 卷内的成长 | 从"外来者"变成"被追问的人"——第一次主动去查"我是谁" |
| 阵营戏份 | 幽都主场（W07/W08）、灰原（W09/W10）、雾乡（W11/W12） |
| 卷末 Boss | **W12 镜像管理者**（镜像城市） |
| 卷末 cliffhanger | "你不是第一次走到这里。去问她，你上一次叫什么。" → **直接逼出第一次转生** |
| 埋下的伏笔 | 名单上有你的字（W08）、碑三「帆」（W11）、世界在褪色＝被反复读取（W12） |
| 回收 | 卷一的"灯只照亮"（W08 灯亮着的地方雾进不来 → 灯是"固定"） |

**这一卷的功能**：把"好奇心"装上。玩家从此不是为了数值推图，是为了知道"我是谁"。

## 第三卷《第二次醒来》

| 项 | 内容 |
|---|---|
| 世界 | W13~W18 |
| 卷题 | 第二次醒来 |
| 主题 | **第一次转生与失去的记忆** |
| 玩家认知 | 我醒来过。醒来时世界没变，只有我变小了 |
| 卷内的成长 | 学会问"代价"：变强要还什么 |
| 阵营戏份 | 雾乡（W13/W15 边缘）、灯阁首次直接出面（W14）、灰原（W16）、锈港（W17）、幽都（W18） |
| 卷末 Boss | **W18 归航信标**（深空遗址） |
| 卷末 cliffhanger | "你的病历不是第一本。上一本，字迹和这一本一样。" |
| 埋下的伏笔 | 碑四「幽」（W15）、碑五「白」（W18）、禁忌实验区＝"固定在最后一刻的世界"（W13） |
| 回收 | 卷二"你上一次叫什么"——不回答，改成"你上一次的字迹"（差一步） |

**这一卷的功能**：把转生这件**玩家每天都会按的按钮**，变成一件让人心里发凉的事。

## 第四卷《没有归途的文明》

| 项 | 内容 |
|---|---|
| 世界 | W19~W24 |
| 卷题 | 没有归途的文明 |
| 主题 | **世界之间存在连接** |
| 玩家认知 | 残域不是废墟，是被留下来的东西。而且有人**故意**让它们留着 |
| 卷内的成长 | 从"查自己"转到"查灯阁"——第一次质疑灯阁 |
| 阵营戏份 | 锈港（W19/W22）、灯阁开门（W20）、幽都（W21）、灰原（W23）、雾乡（W24） |
| 卷末 Boss | **W24 断光执行者**（断光之城） |
| 卷末 cliffhanger | "你不该回来。灯主也只是想留住你们——他没告诉你们，留住是要还的。" |
| 埋下的伏笔 | 碑六「默」（W21）、碑七「锈」（W22）、前任执灯者的名字（W24） |
| 回收 | 谜团一（残域＝保存的世界残片）在这一卷完成 70%；谜团六（灯主动机）首次转述 |

**这一卷的功能**：把矛头从"坏世界"转向"好人的好意"。从此玩家打的每一架都有点不对味。

## 第五卷《第八个名字》

| 项 | 内容 |
|---|---|
| 世界 | W25~W30 |
| 卷题 | 第八个名字 |
| 主题 | **主角过去的身份** |
| 玩家认知 | 我的名字早就写在灯阁的旧记录里 |
| 卷内的成长 | 接受"我是第八位执灯者"，并开始想"那我上一次为什么没走完" |

| 项 | 内容 |
|---|---|
| 世界 | W31~W36 |
| 卷题 | 最后一盏灯 |
| 主题 | **残域真正的来源与灯阁的最终选择** |
| 玩家认知 | 我不是后来的执灯者。我比灯阁晚，但比所有灯都早 |

| 卷末 | 灯主问："你愿不愿意让灯熄灭？" → **熄灭 / 继续点燃** |

| 回收 | 谜团一~谜团六全部落地；第九个名字仍留白 |

**这一卷的功能**：把整本书的问题交回给玩家。**不给对错。**

## 节奏与强度分布

按"世界观推进量"分三档（不是按关卡难度）：

| 档 | 世界 | 剧情时长 | 职责 |
|---|---|---|---|
| **普通推进** | 其余 24 个世界 | 20~60 秒 | 世界展示、小线索、人物出现、伏笔 |
| **重要世界** | W04 W08 W11 W13 W14 W15 W16 W20 W21 W22 W25 W26 W27 W28 W29 W31 W32 W34 W35 | 60~180 秒 | 真相推进、阵营冲突、主角身份线 |
| **卷末 Boss** | **W06 W12 W18 W24 W30 W36** | 短而有冲击 | 大事件、核心揭示、cliffhanger |

六卷 Boss = 六卷的**视觉锚点**（也是第一期只做 6 张 Boss 立绘的原因，见 `docs/story/`）。
