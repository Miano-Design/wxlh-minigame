# 《残域》六卷 Boss 剧情表

> 六卷各一个 Boss，也是六卷的**叙事锚点**（第一期只做这 6 张立绘）。
> 每个 Boss 必须回答六件事：**为什么挡在这里 / 他知道什么 / 他与主角是什么关系 /
> 战前一句关键话 / 战败后透露什么 / 留下什么谜团。**
>
> 硬约束：**除了 W36 的灯主，其余五个 Boss 都不许是"血多攻高"的恶人。**
> 他们全部是"出于善意做了错事"，或者"照章办事"。玩家打完要有一种"不该是我赢"的感觉。

---

## W06 轨道主控 —— 第一卷《灯下之地》

| 项 | 内容 |
|---|---|
| 名字 | 轨道主控（Boss）｜轨道废土带｜锈港（造物质地） |
| **为什么挡在这里** | 它在执行一条**没人解除**的旧命令："不许停。"它不知道外面的世界已经结束了 |
| **他知道什么** | 它知道 36 个世界的**编号与位置**——它是残域的"封存环"守备系统 |
| **他与主角是什么关系** | 无关系。**这是玩家遇到的第一个"人以外的东西"**，也是全书唯一一次"敌人真的没有立场" |
| **战前一句关键话** | **"这里没有敌人，只有尚未接到停止命令的机器。"** |
| **战败后透露什么** | **"你们的世界也在这条轨道上。编号已定。"** 然后它自己把灯关了 |
| **留下什么谜团** | 世界为什么有编号？谁编的？（F-10 → W19 回收） |
| 叙事作用 | 教会玩家"灯不是照明"的第一课；把残域从"乱"变成"有秩序" |
| 视觉锚点 | 铁锈橙 + 冷蓝对撞的巨大轨道结构；它停机的瞬间，轨道上亮起 36 个点 |
| 回收 | F-10 首次埋；W05 的轨道图 |

**写作要点**：全程不许把它写"凶"。它最狠的地方是**它很有礼貌**——
它先播报，再开火，而且每次都播报同一个编号。

## W12 蚀冠之王 —— 第二卷《雾中的人》

| 项 | 内容 |
|---|---|
| 名字 | 蚀冠之王（Boss）｜蚀环远征｜雾乡（秘仪质地） |
| **为什么挡在这里** | 他挡着，是为了**不让自己的世界被褪完**。一停就没了，所以他不能停 |
| **他知道什么** | 他知道褪色是**反复读取**的结果；他也知道玩家已经来过 |
| **他与主角是什么关系** | **他是见过玩家的**（不是第八位，是更早的一位执灯者）。他记得，玩家不记得 |
| **战前一句关键话** | **"你来过这儿。上一次，你没走到这儿。"** |
| **战败后透露什么** | **"你不是第一次走到这里。去问她，你上一次叫什么。"** |
| **留下什么谜团** | 玩家上一次叫什么？（F-02 / F-03 → W31 / W32 回收） |
| 叙事作用 | 把"好奇心"装上——玩家从此不是为了数值推图 |
| 视觉锚点 | 黑白冷光的大远景；他每掉一段血就褪掉一层颜色，露出下面更旧的一层 |
| 回收 | 谜团三第 2 层收口 |

**写作要点**：他不是"守关者"，他是**一个不肯让自己被删掉的人**。
"去问她"这三个字，是全书第一次有人给玩家指路。

## W18 白衣院长 —— 第三卷《第二次醒来》

| 项 | 内容 |
|---|---|
| 名字 | 白衣院长（Boss）｜白墙疗养院｜幽都（残响质地） |
| **为什么挡在这里** | 她在"救"病人——**用把人变成记录的方式**。她认为人只要被记得全，就没散 |
| **他知道什么** | 她知道玩家被记过很多次；她手里的病历就是**灯录的早期形态** |
| **他与主角是什么关系** | 她"治疗"过玩家，**不止一次** |
| **战前一句关键话** | **"欢迎回来。病历已经翻到第几页了？"** |
| **战败后透露什么** | **"你的病历不是第一本。上一本，字迹和这一本一样。"** |
| **留下什么谜团** | 病历的编号是"第几本"，那**第一本**是谁写的？（F-11 → W29 回收） |
| 叙事作用 | 把转生从"按钮"变成"让人心里发凉的事" |
| 视觉锚点 | 老式疗养院白墙长廊（`ghost_env` 母版）；先出现字，后出现人 |
| 回收 | 谜团三第 3 层击穿；F-01「白」 |

**写作要点**：她全程温柔，说话慢。**这比凶更吓人。**
她最后那句里的"字迹和这一本一样"，是全书最重要的一句技术性台词——
它同时说了"你来过"和"你是被写出来的"。

## W24 灰袍祭司 —— 第四卷《没有归途的文明》

| 项 | 内容 |
|---|---|
| 名字 | 灰袍祭司（Boss）｜灰烬圣所｜雾乡（秘仪质地） |
| **为什么挡在这里** | 他守的不是门，是**"别再回来了"**。他已经看穿灯主，选择替灯主守门 |
| **他知道什么** | 他知道灯主想留住所有人；他也知道**留住是要还的**。他知道代价是什么 |
| **他与主角是什么关系** | 他认得玩家。他不想伤害玩家，所以他下手最重——**他要把玩家劝回去** |
| **战前一句关键话** | **"香灰底下压着名字。你踩过去了。"** |
| **战败后透露什么** | **"你不该回来。灯主也只是想留住你们——他没告诉你们，留住是要还的。"** |
| **留下什么谜团** | 代价是什么？灯主为什么不告诉？（F-08 / F-13 → W30 / W36 回收） |
| 叙事作用 | 把矛头从"坏世界"转向"好人的好意"——**打完之后，玩家会开始怀疑自己该不该赢** |
| 视觉锚点 | 香灰与石质遗迹（`mystic_ruins` 母版），香灰底下压着一个名字 |
| 回收 | 谜团二第四层（封存）；谜团六首次转述 |

**写作要点**：他是全书唯一一个"已经知道答案、却选择闭嘴"的人。
他打完说的不是威胁，是**一句心疼**。

## W30 熔芯核心 —— 第五卷《第八个名字》

| 项 | 内容 |
|---|---|
| 名字 | 熔芯核心（Boss）｜熔芯之炉｜锈港（造物质地） |
| **为什么挡在这里** | 它就是"维持燃烧"这件事本身。**停了，就会有人在天亮前冻死** |
| **他知道什么** | 它知道停火的**后果**（这是灯主的账） |
| **他与主角是什么关系** | 它把玩家当成"要关火的人"，也就是**要杀人的那个人** |
| **战前一句关键话** | **"别关。关了你就知道为什么我们一直烧着。"** |
| **战败后透露什么** | **"你关掉的每一炉，都有人在天亮前冻死。灯主数过。你数过吗？"** |
| **留下什么谜团** | 灯主到底付出了多少？炉壁上被凿掉的那行字是谁凿的？（F-09 → 第一期留白） |
| 叙事作用 | **谜团六的正面交锋**。到这里玩家必须承认：灯主不是坏人，他只是不肯结束 |
| 视觉锚点 | 熔炉纵深、硬光源（`tech_base` 母版）；整张图在响 |
| 回收 | F-13 代价；F-09 第二次触碰 |

**写作要点**：它是机器，所以它**不会说谎**。
"你数过吗？"这四个字是全书最重的一问——它不问对错，它问**你有没有替别人数过**。

## W36 终焉·灯主 —— 第六卷《最后一盏灯》（终局）

| 项 | 内容 |
|---|---|
| 名字 | 终焉·灯主（Boss）｜灯阁王座｜无阵营（灯阁） |
| **为什么挡在这里** | 他不挡。**他坐在灯里等。**他等的是有人走到这里，并且敢开口 |
| **他知道什么** | 他什么都知道：残域的来源、灯的五件事、九碑、你被重载过几次 |
| **他与主角是什么关系** | **他写下第八个名字。他按下过每一次重载。他一直在等这一次。** |
| **战前一句关键话** | **"灯是我点的。你也是。"** |
| **战败后透露什么** | 全部真相；然后他问：**"你愿不愿意让灯熄灭？"** |
| **留下什么谜团** | **第九个名字**（第一期不给答案） |
| 叙事作用 | 把整本书的问题交回给玩家——**不给对错** |
| 视觉锚点 | 王座其实是**一盏灯**（`god_hall` 母版）；整座灯阁就是这一盏 |
| 回收 | F-01~F-18 全部（F-09 除外） |

### 他的立场与错误（写死，不许软化）

```
立场：只要灯还亮着，文明就没有真正消失。
错误：他不愿意接受"世界已经应该结束"。
方式：不劝、不威胁、不反悔。问完就等。
```

**他的三句台词（从轻到重）**：

1. `"灯是我点的。你也是。"`（战前）
2. `"我看着你熄过一次。你又亮了。"`（战斗中，第八次残响）
3. `"你愿不愿意让灯熄灭？"`（战后，唯一的问题）

### 终局的两个选项

| 选项 | 第一阶段影响（**只做这三处**） |
|---|---|
| **熄灭** | 记录"熄灯"标记 · 最后一段台词换成熄灯版 · 卷宗里多一页"熄灭记录" |
| **继续点燃** | 记录"续灯"标记 · 最后一段台词换成续灯版 · 卷宗里多一页"续灯记录" |

> 战斗、关卡、掉落完全一致。**第一期不拆两套流程。**
> 两个选项中，**第九块碑都不会亮起来写字**——那件事留给以后。
