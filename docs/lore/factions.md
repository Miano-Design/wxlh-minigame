# 《残域》四大阵营

> 真源：`js/data.js` 的 `FACTIONS` / `FACTION_COUNTER` / `FACTION_GLYPH`、
> `js/dungeon.js` 的 `THEME_FACTION`。四阵营名一字不改，克制环也一字不改。

---

## 〇、它们不是四个国家

四阵营不是"四个王国"。它们是**四批活下来的人**——
每一批人，当初都是跟着**一位执灯者**从一片残片里走出来的。

> **火是同一盏灯给的，路是四个人指的，于是人分成了四堆。**

所以四阵营的底色是全书最重要的设定之一：
**它们的存在本身，就是"九碑前七位"存在过的证据。**

---

## 一、灰原（灰烬平原 · 前线）

| 项 | 内容 |
|---|---|
| 残片质地 | **滋生（bio）** —— 保存下来的是身体与活物本身 |
| 世界 | W01 黏液巢穴 · W02 潜影窟 · W09 灰烬平原 · W10 天穹废墟 · W16 循环之城 · W23 残域意识层 · W28 真实边界 · W33 世界重启点 |
| 血统倾向 | 狼人、泰坦 |
| 代表人物 | **黑田宗一**（C111 · 狼人 · 终极狂战）—— 灰原前线统领 |
| 核心理念 | **往前推。活着的意义就是还没停下。** |
| 历史 | 第一批走出来的人里，那位执灯者的名字是**「灰」**。他带出来的残片全在"还在长"——感染、藤蔓、卵。所以他定下第一条规矩：不许在原地等 |
| 与别人的矛盾 | 嫌雾乡"只会记账不动手"；看不起锈港"捡别人剩下的"；和幽都最不对付——**灰原要活的，幽都要走的** |
| 主线作用 | 它是**"生"的一侧**。它存在的每一卷都在提醒玩家：留下是有代价的，但不留也是有代价的 |
| 在终局的选择里 | 天然的"继续点燃"派（不是因为它信灯主，而是因为它受不了停） |

**写作要点**：灰原不是"好战蛮子"。它的规矩是从尸体堆里长出来的：
在一个会自己长大的世界里，停下来就是死。**它的强硬是算术，不是性格。**

## 二、雾乡（哑雾一带 · 术法与谋略）

| 项 | 内容 |
|---|---|
| 残片质地 | **秘仪（mystic）** —— 保存下来的是规则、仪式、被写下来的秩序 |
| 世界 | W04 机关地宫 · W11 记忆档案区 · W12 镜像城市 · W13 禁忌实验区 · W24 断光之城 · W29 最后灯塔 · W35 残域终焉 |
| 血统倾向 | 修真、念动力 |
| 代表人物 | **楚衍**（C059 · 修真 · 精神支配）—— 雾乡的"记名者" |
| 核心理念 | **记住，比活着重要。** |
| 历史 | 那位执灯者的名字是**「雾」**。雾乡是四家里唯一一个**把"记录"当正经事**的：他们抄写、归档、立碑、编号 |
| 与别人的矛盾 | 灰原骂它纸上谈兵；锈港骂它把东西锁起来不给人用；**它自己最怕的是幽都**——因为幽都会"把记录烧掉"（幽都认为该结束的就该忘） |
| 主线作用 | **它是唯一一个发现"世界在褪色"的阵营**（W12 蚀环）。谜团一、谜团二的第一手证据全在雾乡手里 |
| 在终局的选择里 | 分裂：老一代记名者倾向"继续点燃"（记录不能断），年轻一代倾向"熄灭"（一直在记，才是还没结束） |

**写作要点**：雾乡是玩家**最重要的信息源**，但它的信息永远是"抄来的"。
它给你的每一句都可能是别人写的，这一点到 W25 逆流区域会被直接翻出来。

---

## 三、锈港（轨道残骸带旁的打捞港 · 机械）

| 项 | 内容 |
|---|---|
| 残片质地 | **造物（tech）** —— 保存下来的是造物、机器、被执行的命令 |
| 世界 | W06 沉眠水城 · W17 遗忘荒原 · W19 地下圣所 · W22 创造者遗址 · W26 遗民聚落 · W30 人类选择室 · W34 最终灯火 |
| 血统倾向 | 科技、泰坦 |
| 代表人物 | **苍岚零**（C112 · 科技 · 星舰炮手）—— 锈港打捞人 |
| 核心理念 | **没有真正毁掉的东西，只有还没修好的。** |
| 历史 | 那位执灯者的名字是**「锈」**。锈港建在轨道残骸旁边——**它靠拆世界活着**。它捞回来的东西，一半修好了，一半装在自己身上 |
| 与别人的矛盾 | 灰原嫌它把好料都拆了；雾乡嫌它乱动不该动的；**它最怕接灰原的活**——因为幽都的旧账它欠着（它拆过幽都的残片） |
| 主线作用 | **谜团二的技术底座**（W06/W17/W30）。灯的"记录—固定—连接—封存—重载"这套机器语言，是从锈港这里第一次被说出口的 |
| 在终局的选择里 | 天然的中立：谁都用它的机器。**它最后交出去的不是立场，是一份说明书。** |

**写作要点**：锈港是唯一一个"不讨论该不该，只讨论能不能"的阵营。它的回答是全书最轻、也最狠的。

## 四、幽都（残影与精神力的聚居地 · 送行）

| 项 | 内容 |
|---|---|
| 残片质地 | **残响（ghost）** —— 保存下来的是意识、记忆、没散去的人 |
| 世界 | W03 怨声旧宅 · W05 迷雾林海 · W07 裂隙矿坑 · W08 黑潮港湾 · W15 残域核心外环 · W18 深空遗址 · W21 回忆之境 · W27 创造者墓场 · W31 最初残域 |
| 血统倾向 | 念动力、绯红 |
| 代表人物 | **山吹时雨**（C114 · 念动力 · 终极控制）—— 幽都送行人 |
| 核心理念 | **已经结束的，就该让它结束。** |
| 历史 | 那位执灯者的名字是**「幽」**。幽都是四家里唯一一个**不救**的：它只送。它的人替走不掉的东西把话说完，然后关灯 |
| 与别人的矛盾 | 与灰原不共戴天（一个要留、一个要送）；对雾乡冷淡（你们记的，都是我们送走的）；**跟锈港有一笔旧账**（锈港拆过它的残片） |
| 主线作用 | **它是全书的良心，也是灯主唯一的对手。** 谜团六（灯主立场）必须由幽都第一次说破：**"反复留住，是不肯告别。"** |
| 在终局的选择里 | 天然的"熄灭"派（不是因为它恨灯主，而是因为**它是唯一一个愿意把这句话说出口的人**） |

**写作要点**：幽都不是"阴森的地方"。它是四家里**最温柔**的：
它的每一个世界都是"有人还没走完的东西"——**它送行，不驱赶。**

## 五、克制环（一字不改，但给它一个理由）

```
灰原 → 雾乡 → 锈港 → 幽都 → 灰原
（克制方伤害 +15%，被克 −10%）
```

这不是数值设定，是**四家大吵了几百年吵出来的顺序**：

| 关系 | 表面理由 | 底下真正的原因 |
|---|---|---|
| 灰原克雾乡 | "你们只会在纸上写" | 雾乡记下的名单里，有一半灰原的人至今没被承认死了 |
| 雾乡克锈港 | "你们乱动不该动的" | 锈港当年拆的残片里，有雾乡的档案库 |
| 锈港克幽都 | "你们的旧账我认，我不还" | 锈港欠幽都一次没能修好的送行 |
| 幽都克灰原 | "你们不肯让人走" | 灰原救回来的那些人里，有些本来该走 |

> **克制环是"四家都欠着别人一笔"的意思。** 所以同乡组队有加成——
> 语言相通，动作对得上；而互相克制，是历史欠账。

## 六、四阵营在六卷里的出场配比

| 卷 | 主场 | 次要 | 这一卷要立的事 |
|---|---|---|---|
| 一 | 灰原 · 幽都 | 雾乡 · 锈港 | 四家各露一面，**不许有任何一家被写成反派** |
| 二 | 幽都 | 灰原 · 雾乡 | 幽都的"送行"第一次出现，玩家以为那是恐怖，其实是礼貌 |
| 三 | 雾乡 · 灯阁 | 灰原 · 锈港 · 幽都 | 雾乡的"记录"救过一次人，也害过一次人 |
| 四 | 锈港 · 灯阁 | 幽都 · 灰原 · 雾乡 | 锈港交出"灯的说明书"（谜团二技术底座） |
| 五 | 灯阁 · 幽都 | 灰原 | 幽都说破灯主（谜团六首次正面） |
| 六 | 幽都 · 灯阁 | 灰原 · 锈港 · 雾乡 | 最后的选择，四家各说一句，**谁都不劝** |

|---|---|---|---|---|
