## 一、发现的问题（本轮实测，逐条带证据）

| # | 问题 | 性质 | 证据 |
|---|---|---|---|
| 1 | **首页把「挂机收益 + 收取奖励」整块弄丢了** | 回归（2.0 那版首页替换时丢的） | 底栏会给"挂机可领"亮红点（`idleBankGains().seconds ≥ 300`），首页却找不到能收的东西 → 正是"红点亮着、点进去没内容" |
| 2 | **首页红点用 `freeRecruitAvailable()` 判"免费招募"，没带解锁判定** | 假红点 | 新档实测：`freeRecruitAvailable=true` 但 `freeRecruitReady=false`（招`isUnlocked('recruit')` 为假）→ 功能没解锁就亮灯 |
| 3 | **"刚刚发现"在全新档就出现** | 逻辑反了 | 原判据 `clueOf(post)‖clueOf(in)` + 只看 `epilogueSeen` → 还没通关就顶着一条"发现"，且读过也不消 |
| 4 | **`js/overhaul-2.0.js` 里有**两份首页实现** | 死代码/双实现 | `renderHome()` 从来没被调用，真正挂上去的是 `renderHomeBody()`（改一处忘一处就分叉） |
| 5 | 首页"快速整理"里 **背包** 与 **指南** 与别处重复 | 重复入口 | 背包在底栏第二格；指南在「设置」里（父亲大人 §四 点名） |
| 6 | 伙伴详情星级写成 `3 / 5 ★` | 读数像进度条 | `js/sc-roster.js` 详情页 `U.kv('当前星级', …)`（列表页/头部卡早就是 `★★★☆☆`，只有这一处例外） |

## 四、新手流程调整说明（§九）

**没有新增"W00 序章章节"** —— 本轮的任务口径是"不增加内容、只修体验层"，而现有开场**已经覆盖了**
要求的七步（用现有系统串起来，不是新造一章）：

```
进入游戏 → 主画面 gate（含《健康游戏忠告》）
        → 欢迎 welcome → 起名 create（走官方机审）→ 命格 bloodline
        → 灯阁（首页：主角卡 → 当前旅程 → 残域）
        → 第一次探索：点残域 → 点 W01 → **自动播 `in` 剧情** → 自动回世界页
        → 第一次战斗：点第 1 关 → 打 → 结算（奖励 + 战场变化 + 线索）
        → 第一次成长：结算/首页的「成长」入口
```

"第一次 30 分钟"五问的答案（对照当前实现）：

| 问 | 玩家从哪知道 |
|---|---|
| 我是谁？ | 起名 + 命格选择 + **首页主角卡**（Lv / 命格 / 战力，可点进详情） |
| 为什么来这里？ | W01 的 `in` 剧情自动播（"灯阁的记录说这里已经失去活性…"） |
| 为什么战斗？ | 每世界 ARC 的 `conflict/enemyPurpose` + 世界页的机制行 + 战前 `pre` |
| 为什么成长？ | 结算给"战场变化 + 线索"；首页「继续探索」指向下一关，打不动就回成长 |
| 下一步去哪？ | 首页只有一个主按钮（继续探索）；世界页 12 格直给 |
