## 二、迁移写什么、不写什么

**写**（只增不减）：

```
story.w[wid].in     ← 有星（进过这张图）
story.w[wid].mid    ← 第 6 关已通
story.w[wid].pre/post + story.b[wid]   ← 普通难度 12/12 全通（或 bestWorldIdx 证明当年通关过）
story.c[charId].s1  ← 已拥有该角色（"首次获得"真的发生过）
```

**不写**（红线）：

```
关卡星数      —— 旧档里没有"当年几星"的留痕，写就是编数据
任何资源      —— 这是历史资料补全，不是发奖
世界解锁状态  —— 解锁只有一个真相 refreshWorldUnlocks()，剧情字段不参与战斗门禁
s2 / s3       —— "成长里程碑 / 特殊事件"在旧档里没有凭据
```

## 三、判据只认 ID，不认名字

36 个世界在这一轮全换过身份（W05 无归客轮 → 迷雾林海、W12 蚀环远征 → 镜像城市 …）。
存档里存的**永远**是 `W01~W36`；改的只是显示名。

`world_save_compat_audit` 用三条一起钉住：

1. `D.WORLDS` 的 id 必须是 `W01..W36` 连续且不重复；
2. `docs/lore/旧名迁移表.md` 里的"新名"必须与 `js/data.js` **逐字一致**；
3. **去注释之后**的 `js/` 里，旧世界名 0 处、按世界名判进度的写法 0 处。
