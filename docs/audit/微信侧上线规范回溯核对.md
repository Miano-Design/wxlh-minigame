## 五、隐私（**唯一需要人去后台办的一件事**）

### 当年的定案（合规岗 0928R5 + 父亲大人）

- 结论原文：「这版代码**没有第二道硬红线**，只有一条真红线（**剪贴板隐私接口的声明与告知**）」；
- 命名安全走的是官方机审（云函数 `checkname`），不是自建词库。

### 当前代码实测

| 检查 | 结果 |
|---|---|
| `wx.setClipboardData` / `getClipboardData` | **全仓 0 处调用**（`save_export/save_import/code_make/code_claim` 四个剪贴板处理器已整段删除，代码里有说明）→ **剪贴板接口不在运行路径上** |
| `wx.getUserInfo` / `getUserProfile` / `chooseAvatar` / `wx.login` | **全仓 0 处** → 不采昵称/头像，不做显式登录 |
| 登录方式 | 云开发**隐式登录**：云函数里 `cloud.getWXContext().OPENID`（`cloudsave/index.js`），客户端 `wx.cloud.init({env, traceUser:true})` |
| 上云的明文数据 | 只有 `act` 那一小块**数字**（`loginDays/playMinutes/clears/subMsg/bankFullAt/bankAmount/bankSec` + 会话租约 id/ts）——**不含身份信息** |

**所以代码侧不需要隐私授权 API**；需要的是在 MP 后台把《用户隐私保护指引》按实际采集项声明好
（就上面那一小块数字 + openid）。这件事**只能你在后台做**，我做不了。
