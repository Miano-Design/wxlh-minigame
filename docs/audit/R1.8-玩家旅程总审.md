# 《残域》R1.8 玩家旅程总审

> 视角：**一个完全没玩过的人，第一次打开游戏**。
> 方法：`scripts/player_journey_audit.js` —— 用**真函数**（`Core` / `CV` / `Story` / `BattleUI`，含 `dispatch` 真处理器）
> 把 `BOOT → START → HOME → DUNGEON → WORLD → STORY → BATTLE → RESULT → WORLD_RETURN → HOME_RETURN → GROWTH → BACK`
> 走一遍，每个节点记 7 个字段（page / reason / nextAction / backTarget / stateSaved / visualReady / storyState）。

---

## 一、玩家旅程地图（含割裂点判定）

```
开机 ─ gate(主画面) ─ welcome ─ create(起名) ─ bloodline(命格) ─ 灯阁home
                                                                    │
                          底栏四格（灯阁 / 残域 / 执灯者 / 背包）────┤
                                                                    ↓
                          残域dungeon ─ 点世界卡 ─→ world ─【自动压一层 in 剧情】→ story
                                                                    │  （看完自动 pop 回 world）
                                                                    ↓
                                        world ─ 点第 N 关 ─→ battle（含 Boss 出场序列）
                                                                    │
                                              onEnd → 结算层（奖励 → 战场变化 → 线索 → 下一步）
                                                                    ↓
                                        CV.reset('world') / 'dungeon' → 继续下一关 / 下一世界
                                                                    ↓
                                               …W12 → W13(转生门) → … → W36
```

### 割裂点判定（§二十八：SEAMLESS / NOTICEABLE / BROKEN）

| # | 位置 | 判定 | 理由（代码级） |
|---|---|---|---|
| 1 | 世界页 → 剧情页（自动） | **SEAMLESS** | 同一张场景图（`Story.bg` 与战斗 veil 取同一个 `SCENE[wid]`），压栈不改视觉 |
| 2 | 剧情页 → 战斗页 | **NOTICEABLE** | 页面栈换了（`CV.reset('battle')`）；虽然背景仍是同一张场景图，但战场 UI 整块出现 —— 这是"换页面"最强的一处 |
| 3 | 战斗开始 → Boss 出场序列 | **SEAMLESS** | 出场层是**叠在战场之上**画的（`CV.pageOverlay`），不是新页面；`step()` 在 2.4s 内不推进战斗 |
| 4 | 战斗 → 结算层 | **NOTICEABLE** | 结算层弹在战斗页之上（同一页 overlay，不出画）——比"跳新页"好，但仍是明显的模式切换 |
| 5 | 结算 → 世界页 | **NOTICEABLE** | `CV.reset('world')` 整页重画（不复用战斗帧） |
| 6 | Boss 死亡 → 战场变化那一行 | **SEAMLESS** | 就在结算层里，跟着奖励一起出来，不再跳页 |
| 7 | 场景图未缓存 → 图到位 | **SEAMLESS** | R1.7 修掉了：loading 期画**主题平底**（无几何），到位是淡入不是换画 |
| 8 | 失败 → 重试 | **SEAMLESS** | 出场序列与剧情都**不会再播**（`BATTLE_SEEN` 闸门），直接开打 |
| 9 | 二级页 → 返回 | **SEAMLESS** | 逐页真派发过：都回上一层；底栏格还记现场（页面 + 滚动） |
| 10 | 底栏切格 | **SEAMLESS** | `tabMemo` 保页面 + 保滚动（V1.1.17 起，`ux_audit`/`scroll_fit_audit` 都钉着） |

**结论：10 个里 7 个 SEAMLESS、3 个 NOTICEABLE、0 个 BROKEN。**
最容易让玩家感觉"游戏在切模块"的三处，按顺序是 **② 剧情→战斗**、**④ 战斗→结算**、**⑤ 结算→世界**。
这三处都不是 bug，是"页面/图层切换"本身；要再压下去只有一种做法（战斗页原地长成结算层，
不 `reset` 世界页），那是重做结算架构 —— 属于 §三十 明令不许的那类改动，本轮不做。

## 四、最终判断（只回答两个问题）

**1. 一个完全没玩过的人第一次打开，能不能自然从开始一路玩到 W01，并理解为什么战斗、战斗后发生了什么、去哪？**

**能。** 依据：开局三步四页齐；点世界卡自动播 `in`；看完自动回世界页点关卡；
Boss 关前自动播 `pre`；战斗里 3~4 条残响挂在真事件上；结算给奖励 + 战场变化 + 线索 + 下一步。
全程**不需要玩家手动去找剧情入口**。

**2. W01～W36 是否已经形成连续体验？**

**内容层：是。** 36 世界的 12 项完整度 **36/36**；相邻交接 **35/35 全接上**；
每世界 ≥3 个真战斗剧情节点；36/36 世界都有 Boss 出场与战后变化。

**体验层：机器能证明的到此为止。** "连续玩下来像不像同一个故事"这件事，
只能用眼睛连续看 W01→W03 与六个 Boss 才能下结论 —— **本轮没有实机连打，这一步我不当通过。**
