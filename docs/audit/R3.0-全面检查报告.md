## 二、本轮改动（`ff5781f` 之后）

**① 挂机收益提到当前旅程卡**（回答 GPT 第①问：加）

```
当前旅程
灯阁王座 · 第 3/12 关
[继续探索]                              ← 主按钮不变
挂机收益 ◉300 · ◆3（已攒 30 分）  [领取]   ← 新增：有收益才出现，没有整行不占位
```

- 右边是**小**按钮（不是第二个大按钮），动作仍是既有 `claim_all`；
- **下面那张完整挂机卡保留**（派人分工 / 广告加速在那儿）——同一动作的两个入口，不重复收费；
- 实测：无可领时不出现；有可领时两处都在；文案 `挂机收益 ◉300 · ◆3（已攒 30 …`。

**② `全部系统 ›` → `更多成长 ›`**（回答 GPT 第②问：保留 + 改名，动作不变）

**③ 新增红点尺子 `scripts/dot_audit.js`**（已进总闸）：造出"红点该亮"的状态 → 真渲染目标页 →
断言那颗动作在热区里。6 条全对；另查"全新档不许靠空红点撑门面"（新档仍有 16 个真实入口）。
